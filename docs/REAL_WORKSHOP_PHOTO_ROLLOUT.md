## Publishing route and verification

The Windsor.ai `google_my_business.upload_media` action accepts publicly accessible JPG/PNG URLs, not local `/mnt/data` paths. Therefore website originals must be committed and deployed first. After production deployment returns HTTP 200 for each exact JPG asset, use `https://www.noordtune.nl/images/workshop/<filename>` as the GBP `photo_url` with the categories above. Do not change the existing GBP cover/profile photos. Verify new photo media IDs and categories in Google after upload.
